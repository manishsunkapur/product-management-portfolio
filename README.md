## Product approach

**Strategy → discovery → prioritize → define → prototype → deliver → measure.** Each project states its assumptions, user outcome, trade-offs, and evidence status. Results are not claimed without data.

## Portfolio standards

- Lead with the customer problem and product outcome.
- Show the reasoning behind scope and trade-offs.
- Link the prototype and project-specific measurement plan.
- Keep detailed artifacts organized inside each project folder.
